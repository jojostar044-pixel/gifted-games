## 📋 محتوى كل لعبة

- خمس محطات: الأرقام، الكلمات، المنطق، الأشكال، الإبداع.
- شرح فوري بعد كل إجابة، ونجوم وأصوات وتهنئة بعد كل محطة.
- محطة إبداع تزرع وردة لكل فكرة يكتبها الطالب.
- ملخص للمعلم في النهاية مع زر نسخ (أسئلة الإبداع يصححها المعلم).

> ملاحظة: الإجابات لا تُحفظ بعد إغلاق الصفحة، لذا يُنسخ الملخص قبل الخروج.
